# Smith10 Robustness Check — Provenance

## What this analysis does

Tests whether the BM20 sensorimotor engagement–severity finding
(ICN17 vs WAB-AQ, rho = 0.404, N = 139) replicates in an independent
parcellation (Smith RSN10).

## Provenance chain

1. **Atlas**: `atlas_Smith_RSN20_UnThr.atl` from the ICN_Atlas
   distribution. Contains 10 components, in order:
   RSN01 medial visual, RSN02 occipital visual, RSN03 lateral visual,
   RSN04 DMN, RSN05 cerebellum, **RSN06 sensorimotor**, RSN07 auditory,
   RSN08 executive control, RSN09 frontoparietal
   (perception–somesthesis–pain), RSN10 frontoparietal
   (cognition–language). Verified 2026-10-13.

2. **Per-subject extraction**: xATL files (`M####_ses-##_Smith10.xATL.mat`)
   were generated by running ICN_Atlas on each subject. Those raw files
   are **not redistributed** with this repository. The extracted metrics
   per subject are preserved in `ARC_06_v3_Smith10_Master.mat`.

3. **Analysis**: `scripts/ARC_06_v3_Smith10_Robustness.m` reads the
   extracted metrics and produces the manuscript's severity
   correlations.

4. **Validation**: `scripts/ARC_06_validate_Smith10.m` reproduces the
   key manuscript number from the preserved master table alone. Running
   it should print:
S06 sensorimotor: rho = +0.318, p = 0.0002, N = 139

text

## Sample definition

- Aphasia only.
- Rest-only participants excluded (36 IDs; see project handoff).
- Restricted to the BM20 primary sample via non-NaN `C2_ICN17_IRi`
in `ARC_03b_v3_Master_Wide.mat`.
- Resulting N = 139, matching the BM20 primary analysis.

## Method

- Partial Spearman correlation of network IRi with WAB-AQ,
controlling for age, sex, days post-stroke.
- Covariate adjustment via MATLAB's `partialcorr` with
`'Type','Spearman'` (rank-based).
- FDR (Benjamini–Hochberg, q < 0.05) applied across the 10 networks.

## Known limitations

- Smith10 S06 is not identical to BM20 ICN17 (broader sensorimotor
territory). The comparison is approximate.
- S07 auditory also correlates with severity (rho = +0.225,
p = 0.0086, N = 139). The robustness claim is therefore not
sensorimotor-exclusive.
- The raw per-subject xATL files are not archived. The analysis is
reproducible from the master table but the extraction step is not.
